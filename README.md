# Freight Rate Prediction

Reproducible solution for the Spotter ML assessment. Tested with Python 3.12.14.

## Run

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python train.py
python score.py --predictions validation_predictions.csv --december-predictions data/december_chart_inputs.csv
```

Run these commands inside this folder. Dependencies are pinned to the versions used to generate the delivered results. The requirements cover training and scoring; no GPU is needed. The report is already included; regenerating it additionally requires reportlab==4.4.9 (or a compatible 4.x version) and `python make_report.py` after scoring.

## Inputs

Place the supplied files in `data/` with these exact names:

- `train_test.csv`: 48,000 labeled development loads, January-October 2025.
- `validation.csv`: 12,000 unlabeled November-December loads.
- `validation_predictions_template.csv`: final IDs and predicted_rate placeholder.
- `december_chart_inputs.csv`: 31 fixed-scenario rows. Its predicted_rate column is overwritten by training; other columns are retained.

The local review ZIP includes these inputs. `.gitignore` excludes supplied data, fitted binary models and development prediction diagnostics from ordinary Git commits. A reviewer can reproduce the results using the assessment files. Generated final predictions and the December chart are included. `results/december_predictions.csv` is a delivery copy of the completed December inputs.

## Method

The primary model uses the same input fields available for both final loads and the fixed December scenario. Features: pickup, delivery, equipment, distance, cleaned weight, a missing-weight indicator, weekday sine/cosine, annual sine/cosine, and elapsed days. load_id is used only for alignment. Coordinates and external-looking signals are not required by this model.

HistGradientBoostingRegressor predicts dollars/mile under absolute loss, weighted by distance; predictions are multiplied by distance. Thus the weighted absolute training objective is proportional to dollar MAE. Missing/invalid weights are represented as NaN. Categories are encoded using training rows only; unseen cities are mapped to missing and handled by the estimator. No target values are removed or clipped. The output positivity floor is a defensive guard, not a performance calibration.

## Validation

- Train January-July, validate August; train January-August, validate September.
- Compare 15 versus 31 leaves using mean MAE across these two windows.
- Freeze the selected 31-leaf configuration; test once on October (training January-September).
- Refit on all January-October rows to generate final predictions.
- The fixed iteration count avoids an internal random early-stopping split.
- A September-only sensitivity test adds market_index and quote_signal. These were not used in the final model: they worsened this test, are absent from the December schema, and their provenance is unspecified. This is not proof of leakage.

October MAE: 114.35 USD; baseline MAE: 253.85 USD. October RMSE: 649.73 USD. These are internal temporal-test results, not Spotter's hidden evaluation scores. No November/December labels are available. See `results/metrics.csv`, `results/data_audit.json`, `results/summary.json` and the report.

## Outputs and limitations

- `validation_predictions.csv`: exactly 12,000 unique load_id values and positive rates in template order.
- `scorer_results/candidate_december.png`: generated by the provided scorer.
- `Freight_Rate_Report.pdf`: methodology, results, limitations and required chart.
- `results/model.joblib`: local fitted model; load only trusted model files.

Eight cities in final inputs are unseen during training. Mapping to missing provides a fallback, not city-specific knowledge. An October stress test masking both cities yields MAE 130.76 USD, but is not a measured score on the genuinely new cities. Extreme errors and temporal drift remain concerns. Only ten months of one year are labeled; annual seasonality and December extrapolation are uncertain, and this model does not explicitly model holidays. The scorer checks format and produces the chart; Spotter computes hidden metrics separately.
